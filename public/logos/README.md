# Logos de cadenas de farmacias

Coloca aquí los logos oficiales (PNG con fondo transparente, idealmente ~128×128
o cuadrados; SVG también sirve). Luego avísame y asocio cada archivo a su cadena
con el campo `file` en `CADENAS` (src/v2/Resultados.jsx).

Sugeridos:
- inkafarma.png      (InkaFarma)
- mifarma.png        (MiFarma — hoy se obtiene de logo.dev, pero un PNG oficial es mejor)
- arcangel.png       (Boticas Arcángel)
- boticas-salud.png  (Boticas y Salud / BTL)
- universal.png      (Farmacia Universal)
- superfarma.png     (Superfarma)
- fasa.png           (Fasa)

Si una cadena no tiene archivo aquí, se muestra un monograma con el color de la marca.
